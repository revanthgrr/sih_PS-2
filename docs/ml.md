# 🧠 Jatayu (AeroReady AI) — Machine Learning & Explainability

---

## 1. Multi-Model Architecture Overview

Jatayu implements three independent, complementary ML models loaded at runtime via a thread-safe singleton `ModelManager`.

| Model | Purpose | Technique | Target Metric |
|---|---|---|---|
| **Model A: Anomaly Detection** | Early-warning deviation detection | Isolation Forest | Contamination = 8%, 120 Estimators |
| **Model B: Failure Risk** | Probability of required intervention in next 20h | XGBoost Classifier | ROC-AUC: ~0.88, F1: ~0.86 |
| **Model C: RUL Regressor** | Estimated Remaining Useful Life (Flight Hours) | XGBoost Regressor | MAE: ~8.8h, RMSE: ~17.5h |
| **Explainability (XAI)** | Local factor attribution for every prediction | SHAP (TreeExplainer) | Top-4 Attributed Drivers |

## 2. Feature Engineering Pipeline

Signals undergo continuous temporal and statistical transformations:
- **Baseline Deviations**: $x_{\text{dev}} = x_t - x_{\text{baseline}}$
- **Rolling Window Statistics**: 5-period rolling mean, std deviation, min, max
- **Rate of Change**: $\Delta x / \Delta t$
- **Harmonic Slope**: Approximate linear trend over recent operational intervals
- **Airframe Flight History**: Accumulated flight hours, cycles, and operating hours since major depot overhaul

### Data Leakage Prevention
To prevent temporal data leakage, training and test datasets are partitioned strictly by complete airframe trajectory (grouped k-fold on `aircraft_id`). Sensor readings from future sorties of an aircraft are never randomly intermixed with past training rows.

## 3. Explainable AI (SHAP) Protocol

Every high-risk alert generated by the system presents a **"Why?"** breakdown attributing the specific sensor drifts influencing the model:

```
[42%] Vibration Trend Increasing  ──> +48% above harmonic baseline
[31%] Hydraulic Line Pressure Drop ──> Dropped from 3000 to 2580 psi
[18%] Elevated Temperature Drift ──> +14°C above rolling mean
[ 9%] Operating Hours Accumulated ──> 240 hours since major service
```

*Note: In compliance with technical guidelines, feature contributions are transparently communicated as model statistical influence rather than confirmed physical causality.*
